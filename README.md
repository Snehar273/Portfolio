## ⚡ Quick Start

### Option 1 — Open Locally
```bash
# Clone the repo
git clone https://github.com/Snehar273/portfolio.git

# Just open the file — no server needed
open index.html      # Mac
start index.html     # Windows
```

### Option 2 — Deploy to Vercel (get a live URL)
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy from your project folder
vercel

# Follow the prompts → get your URL instantly!
```

### Option 3 — Drag & Drop Deploy
1. Go to [vercel.com](https://vercel.com) → Login
2. Click **Add New Project** → **Browse**
3. Upload `index.html`
4. Get your live URL in 30 seconds ✅

## 🎨 Customization Guide

Want to fork and use this for your own portfolio? Here's what to change:

```
In index.html:

1. Name          → Search "Sneha" → replace with your name
2. Email         → Search "ssnehar36@gmail.com"
3. Phone         → Search "+91 86107"
4. LinkedIn URL  → Search "linkedin.com/in/sneha"
5. GitHub URL    → Search "Snehar273"
6. Projects      → Find <!-- PROJECTS --> section
7. Avatar text   → Search "SR" → change to your initials
8. Stats         → Find .hero-stats section
9. Skills        → Find <!-- SKILLS --> section
10. Theme color  → Change --accent in :root (default: #a78bfa)
```
